# BeforeJoin v2 prototype

A complete, simplified HTML/CSS prototype for a decision-first workplace
research product.

Open `index.html` in a browser. No build step or JavaScript is required.

## Pages

- `index.html` — start or continue research
- `brief.html` — concise company decision brief
- `compare.html` — compare two companies without scoring them
- `saved.html` — saved research
- `support.html` — help and contact
- `states.html` — essential empty, loading, and error states

The original `../beforejoin-prototype/` directory is intentionally unchanged.
