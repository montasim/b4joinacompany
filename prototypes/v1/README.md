# BeforeJoin prototype

A static HTML/CSS prototype for a decision-first workplace research product.

Open `index.html` in a browser. No build step or JavaScript is required.

The prototype demonstrates:

- company and decision-context search;
- a cited company decision brief;
- repeated evidence signals and time context;
- interview and offer questions generated from evidence;
- verified website, LinkedIn, career, job, and salary signals;
- private notes, comparison, and watchlist concepts.
