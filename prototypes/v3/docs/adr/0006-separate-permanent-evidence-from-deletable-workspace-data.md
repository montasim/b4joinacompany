# Separate permanent evidence from deletable Workspace Data

Published Snapshots, Stories, and Research Sources remain immutable research evidence, while all Workspace Data is user-controlled and permanently deletable. Deleting a User Account immediately revokes its Website and Extension sessions, removes active Workspace Data within 24 hours, and allows encrypted backup copies to expire within a documented 30-day window; only minimal anonymized operational records may remain.
