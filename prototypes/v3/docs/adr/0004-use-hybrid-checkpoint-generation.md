# Generate checkpoints from deterministic evidence bundles

Company resolution, Story indexing, recurring signals, Hiring Signals, Salary Evidence, and Evidence Bundle retrieval will remain deterministic and locally processed. Gemini or Groq may turn only the supplied Evidence Bundle into context-specific questions and summaries, with citations plus provider, model, prompt version, and Published Snapshot recorded on the Checkpoint Revision; when generation is unavailable, the Research API returns a deterministic template-based checkpoint.
