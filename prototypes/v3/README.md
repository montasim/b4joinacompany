# BeforeJoin v3 prototype

V3 keeps the simple workflow from v2 but makes the product's importance
immediately visible: it turns many workplace reports and official sources into
a small set of questions a candidate can verify before joining.

Open `prototype-map.html` for the complete build reference or `index.html` to
start the user journey. No build step or JavaScript is required.

## Pages

- `prototype-map.html` — linked inventory of every planned screen
- `index.html` — research and product thesis
- `company-match.html` — explicit ambiguous-company resolution
- `context.html` — optional role, stage, and decision priority
- `brief.html` — evidence-to-question decision checkpoint
- `ask.html` — company-scoped, cited AI answer
- `compare.html` — compare unresolved questions, not scores
- `saved.html` — saved decisions
- `history.html` — immutable checkpoint revisions and explicit refresh
- `export.html` — PDF and Markdown export choices
- `notifications.html` — evidence update notices
- `auth.html` — public sign-up and sign-in
- `access.html` — regular-user and administrator post-login routing
- `signup.html` — email/Google account creation
- `recover.html` — password recovery
- `answer.html` — record a private checkpoint answer
- `account.html` — profile, notifications, sessions, and workspace privacy
- `pair-extension.html` — short-lived extension pairing approval
- `method.html` — evidence and generation method
- `support.html` — help and source corrections
- `admin.html` — restricted owner operations
- `states.html` — empty, loading, Evidence Gap, quota, sync, and error states

The v1 and v2 prototype directories are intentionally unchanged.
